# Large task lists and unresponsive controls

The user reported that every button was laggy on the just-published public site, with9119overdue tasks. The earlier bulk test measured completing a large set; it did not sufficiently verify ordinary interaction while thousands of unfinished cards remained mounted. No user's records were read, completed or deleted in this investigation. The user's current browser was not attachable through computer-use; reproduction used isolated synthetic data in Playwright MCP Chromium158.0.8127.38.

An isolated public fixture reproduced411,940HTML elements,18,238task cards (Calendar plus hidden Tasks), and account-menu click-to-open samples613/585/535ms. The corrected local fixture renders3411elements/80cards and samples42/39/37ms. Startup of the corrected local fixture was475ms. Baseline startup in before.json includes the menu checks and must not be compared as an equivalent cold-start metric. These are individual browser measurements on this Mac, not physical-phone, GPU utilization or battery benchmarks.

## Change

Calendar sections, Tasks, Dashboard active/completed lists and the priority matrix now mount at most40task cards per page. Previous/Next at both ends keep the rest reachable. Group totals, search, filters, classifications and bulk overdue completion still use the full stored collection. Matrix counts remain global; only its card markup is paged. No storage/schema/API format changed, no task trimming is performed and completing all still covers every overdue record rather than only the visible page. Page positions clamp after removals, reset across account contexts, and keep separate date/filter/group/search contexts. The helper bounds its position cache. Normal checkbox/card motion, drawer/section open/close, task editor transitions, keyboard focus and the two button interaction rules remain available.

This is a website-only correction to the user's authorized public release and reported live regression. The existing app checkpoint remains frozen under the mobile release gate; no new native synchronization/build/installation was performed for this website troubleshooting request. Native large-list parity remains pending its next explicit release instruction. No GitHub main push, database migration, secret/configuration change or billing upgrade is included. The unrelated HTTP/0009 OAuth drafts are excluded from the clean deployment source.
