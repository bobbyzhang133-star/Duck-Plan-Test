# DuckPlan presentation speaker notes

## 1. DuckPlan

Introduce this as the frontend UI/UX contribution to the existing DuckPlan group project. The application was improved in place; it was not rebuilt and backend functionality was preserved.

## 2. Before → After

These screenshots were captured before and after the yellow redesign using the existing demo data and the same desktop viewport. The before image shows the previous frontend iteration, not the very first version of the project.

## 3. A dashboard with a clear purpose

Show that the playful visual layer still serves planning. Task cards, deadlines, calendar links, progress, and the weekly summary use the existing task data rather than invented statistics.

## 4. One original character. Six expressions.

Explain the original shaded SVG duck with expressive eyes, glasses, orange feet and beak, and a celebration flag. States adapt to task progress and evening planning. This image is an illustration-state study, not a data dashboard.

## 5. Make progress feel satisfying

Describe the completion sequence: checkbox toggle, existing data update, then visual feedback. The celebration reflects today’s plan, not every task in the account. Undoing completion removes stale congratulations. Motion can be disabled and system reduced-motion settings are respected.

## 6. Keep the planner useful

The two screenshots show the weekly calendar and task organization. The redesign changes presentation and interaction feedback while preserving existing task and scheduling behavior.

## 7. Designed for different screens and preferences

Show dark mode and the full mobile layout. Wide calendar grids scroll inside their panels. Explain that the character remains visible when motion is disabled; progress values and status messages continue to update.

## 8. My contribution & verification

Name the main new files: duck-mascot.js, duck-interactions.js, duck-theme.css, and the duck favicon. index.html and planner-ui.js connect the UI. The existing task model and persistence routines were preserved. Work remains on feature/duckplan-ui and was not committed, pushed, merged, or deployed.
