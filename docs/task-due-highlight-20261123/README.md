# Due highlights on task cards

Dated tasks have a red background behind the Due row in the Calendar task panel and behind the date and time in the Tasks list. The treatment covers timed and end-of-day deadlines. Cards without a deadline keep a neutral date field. Cache version is v142.

PASS in local Chromium 157.0.8103.79 at 1280px Calendar, 835px Tasks in dark mode, 390px touch-emulated Tasks and 320px touch-emulated Calendar. All dated cards have a visible highlight, the Work field stays transparent, the date fields fit, and the editor opens and closes. Deadline text contrast in the checked cards is at least 4.76:1. Nine task-card tests and two service-worker tests passed.

NOT RUN for signed-in accounts, installed PWA and native devices. The change is in the local web preview.
